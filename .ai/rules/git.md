# Git 操作规则

## 默认权限

除非用户在当前任务中明确授权：

- 不创建或切换分支；
- 不暂存文件；
- 不创建提交；
- 不推送远端；
- 不创建、合并或关闭 Pull Request；
- 不改写历史；
- 不创建或删除标签。

完成任务不以提交代码为前提。

## 允许的只读检查

Agent 可以按任务需要执行：

- 查看工作区状态；
- 查看差异和提交历史；
- 查看当前分支和远端配置；
- 比较文件或提交；
- 定位已有改动来源。

只读检查也不得暴露凭据或无关敏感信息。

## 获得授权后

- 明确仓库、分支、文件范围和目标远端；
- 提交只包含本任务相关改动；
- 不混入用户或其他 Agent 的无关改动；
- 提交信息准确描述行为变化；
- 推送前报告测试状态和已知风险；
- 禁止使用强制推送，除非用户对确切分支明确授权。

## 禁止的默认恢复方式

不得使用可能丢失工作区内容的命令来处理未知改动，包括硬重置、强制检出覆盖和无确认清理。需要恢复或删除内容时，先解析精确目标并获得相应授权。
