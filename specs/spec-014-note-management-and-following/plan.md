- 增加可交付的浏览器品牌图标；
- 建立作者安全编辑图文、视频元数据与视频封面的闭环；

- 保持推荐排序、互动、通知、视频播放和互关私信语义不回归。

## 4. 数据与事务设计重点

- 内容版本必须独立于会被浏览量更新影响的通用 `updatedAt`；
- 旧媒体在数据库提交前保持有效，新媒体在事务失败时可回收；
- 删除事务不能同步持有锁等待慢文件系统；
- 删除通知后未读统计必须从权威数据恢复；
- 关注游标绑定当前用户，不能跨账号重放；
- 编辑和删除必须使用数据库条件语义处理竞态，不依赖前端按钮禁用。

## 6. 风险与控制

| 风险 | 控制 |
| --- | --- |
| 旧媒体已删但数据库保存失败 | 数据库成功前不清理旧对象，新对象使用持久化待清理标识 |
| 数据库已删但媒体删除失败 | 事务前持久记录对象，提交后可重试回收 |
| 浏览量触发错误编辑冲突 | 使用独立内容版本，不直接使用通用 `updatedAt` |
| 非作者通过媒体 ID 越权引用 | 服务端按笔记和作者白名单验证现有媒体 |
| 视频替换绕过 UI | 后端拒绝视频字段和类型变化 |
| 删除导致通知/未读错误 | 事务删除相关通知并按数据库重算未读 |
| 取消关注破坏私信历史 | 保留会话与消息，只按互关条件禁用发送 |
| 关注列表泄露关系 | 只提供当前用户私有接口，不接受目标用户 ID |
| 模态框产生双滚动 | 关注列表内部滚动并按 SPEC-005 验收 |
