## 最终确认前直接修复记录

- 用户授权：由协调 Agent 直接修改，不创建实施或验收 Agent；
- 原始复现：无登录 Cookie，从 `http://localhost:3000` 打开首页时，浏览器拦截对 `http://127.0.0.1:3001` 的频道和会话请求，频道导航只剩“推荐”并显示加载失败；
- 对照证据：同一匿名请求直接访问 `/api/v1/channels` 返回 `200`，说明频道控制器本身没有登录门禁；
- 根因：`FRONTEND_ORIGIN` 配置为 `http://127.0.0.1:3000`，CORS 不接受等价的 `http://localhost:3000`；
- 修复：非生产环境对回环来源同时允许 `localhost` 与 `127.0.0.1`，生产环境仍只允许明确配置来源；
- 修复后原场景：频道和匿名会话请求均为 `200`，13 个频道正常显示，无 `lbb_session` Cookie，也不显示“频道加载失败”；
- 后端 CORS 测试：`4/4` 通过；
- 全量项目测试：前端 `53/53`、后端 `65/65` 通过；
- 正式匿名首页 E2E：`19 passed / 0 failed / 8 skipped`；
- 格式、后端与 E2E Lint/类型检查、后端构建、差异检查通过；
