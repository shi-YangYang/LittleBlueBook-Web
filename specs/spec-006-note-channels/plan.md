- 新增频道表和笔记频道关系；

- 为既有笔记回填内部未分类频道；
- 建立非空外键、删除保护和频道分页索引；
- 验证空库、既有笔记库和重复初始化。

## 2. 后端频道能力

- 新增公开频道列表服务和接口；
- 发布 DTO、multipart OpenAPI 和服务新增 `channelCode`；
- 校验频道存在、启用、公开和可发布状态；
- 推荐保留全量聚合；
- 新增公开频道信息流和频道隔离游标；
- 详情返回可公开频道信息；
- 个人笔记保持全部内容；
- 补充服务、控制器和集成测试。

## 3. 发布页

- 读取服务端频道列表；
- 在正文与话题之间增加单选频道字段和选择面板；
- 实现加载、失败、重试、必填、键盘和焦点行为；
- 将 `channelCode` 加入 multipart；
- 保留频道选择经过 401 重新认证；
- 更新发布测试。

## 4. 首页频道

- 移除前端硬编码频道数组和“视频”占位；
- 读取公开频道列表并在“推荐”后渲染；
- 使用 `?channel={code}` 驱动当前频道；
- 实现选中态、直达、刷新、前进后退和返回推荐；
- 接入频道信息流、切换取消/忽略旧请求、独立空状态和错误；
- 保持推荐聚合和滚动恢复。

## 5. 详情与回归

- 新笔记详情展示频道标签并导航到频道；
- 历史未分类详情不显示标签；
- 停用频道详情保持可访问；
- 个人页全部笔记和卡片布局保持不变；
- 保留自适应滚动模型。

## 15. 最终确认前匿名频道修复

- 用户明确授权协调 Agent 直接修复，不创建新的子 Agent；
- 根因是本地开发从 `localhost` 打开前端时，后端 CORS 仅允许配置的 `127.0.0.1` 来源；
- 非生产环境为配置的回环来源增加 `localhost`/`127.0.0.1` 等价别名，生产环境仍保持单一明确来源；
- 新增后端 CORS 预检测试和无登录 Cookie 的 `localhost` 匿名首页正式 E2E；
- 本地原场景复现、后端测试、全量前后端测试、格式、Lint、类型检查、后端构建和定向 E2E 通过；
- 该修复不改变频道公开业务规则，仅保证既有公开边界在本地开发地址别名下正常生效。

## 16. 最终确认前频道加载过渡修复

- 用户明确授权协调 Agent 直接修复，不创建新的子 Agent；
- 根因是频道接口快速返回空数组时，`NoteFeed` 会立即结束初始加载，骨架屏可能只渲染一帧；
- 首屏加载增加 `300ms` 最小展示时长，接口耗时超过该时长时不叠加额外等待；
- 空状态和错误状态均在稳定的加载过渡后出现；
- 新增定向单元测试和正式 Chromium 频道切换 E2E；
- 发布相关定向测试、全量前后端测试、格式、Lint、类型检查、前端构建和差异检查通过。
