# SPEC-011 实施计划

- Spec：`specs/spec-011-engagement-and-messaging/spec.md`
- 当前 Spec 状态：Accepted
- 计划状态：Completed
- 负责人：协调开发 Agent
- 实施约束：只有用户确认完整 Spec 后才能创建一个新的实施 Agent；数据库、后端、WebSocket、前端和 E2E 必须由同一 Agent 串行完成，实施 Agent 不得创建子 Agent。

## 1. 实施目标

- 把现有一级评论扩展为两级扁平回复；
- 建立评论/回复点赞和事务性通知；
- 建立隐私安全、并发正确的笔记浏览量；
- 建立互关用户一对一私信、未读和已读闭环；
- 建立单实例 WebSocket 实时同步与 HTTP 断线补偿；
- 保留现有认证、信息流、个人主页、通知、资料和滚动模型。

## 2. 预计影响范围

### 数据库

- 扩展评论层级和删除占位状态；
- 新增评论点赞；
- 扩展通知类型和目标关系；
- 新增笔记浏览总数和去重主体；
- 新增私信会话、参与者已读边界和消息；
- 新迁移的空库/历史库兼容测试。

### 后端

- `interactions` 评论读写、回复分页、删除占位和评论点赞；
- `notifications` 新类型、事务生成、定位和降级；
- `notes` 浏览上报、去重和列表/详情读模型；
- 新 `messages` 模块、DTO、OpenAPI、权限、分页、幂等和已读；
- WebSocket 握手认证、用户绑定、推送、重连同步边界；
- 可能需要新增与 NestJS 当前版本匹配的 WebSocket 运行时依赖。

### 前端

- 笔记详情评论项、回复预览、展开、点赞、删除和定位高亮；
- 评论输入器回复目标和登录草稿恢复；
- 首页、频道、个人主页与详情浏览量；
- 通知页新类型和评论深层定位；
- 共享左侧私信入口和未读徽标；
- 他人公开主页私信入口；
- `/messages` 双栏会话和聊天页；
- WebSocket 连接、去重、重连、页面可见性已读和 HTTP 同步；
- 相关组件测试。

### E2E

- 新增 SPEC-011 正式 Playwright 场景；
- 两个独立上下文实时消息、未读和已读；
- 至少三账号的评论、回复、通知和互关权限；
- 浏览 Cookie 去重与作者排除；
- 更新受影响的认证、详情、个人主页、通知和高宽/滚动回归；
- Browser E2E 不进入常规 CI。

## 5. 风险控制

- 不用无界递归查询表达两级评论；
- 删除占位必须同时保护子回复、清理点赞并排除有效总数；
- 通知与互动使用单事务，不建立双写中间状态；
- 不使用 IP、User-Agent 或设备指纹去重浏览；
- 浏览计数使用原子更新，不依赖前端累加；
- 消息持久化先于 WebSocket 推送；
- 所有私信读写逐次重新校验会话和互关权限；
- 不把 Redis、消息队列、多实例广播、陌生人私信或内容审核扩入当前实施；
- 引入 WebSocket 依赖时必须与 Node.js 24、当前 NestJS 和锁文件版本兼容；
- 不修改 CI 的手动触发和 Browser E2E 边界。
