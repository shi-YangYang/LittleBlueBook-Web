# 项目使命

状态：产品方向已初步确认，具体使命与首期范围待完善

## 文档目的

本文件定义 LittleBlueBook-Web 的长期产品使命、目标用户、核心价值和不可牺牲的产品原则。它是后续路线图、技术决策和功能 Spec 的上位依据。

## 当前已确认

- 项目将作为大型 Web 系统进行开发和维护。
- 项目名称为“小蓝书”（LittleBlueBook-Web）。
- 产品是参考小红书内容社区模式构建的 Web 社区。
- 当前项目范围仅包含 Web 端，不规划或记录 App 端交付。
- 产品价值定位聚焦男性用户和男性社区，与小红书的主要用户定位形成差异化。
- 项目采用 SDD（规格驱动开发）。
- 项目使用协调开发、独立实施、独立验收的多 Agent 协作模式。
- 具体功能范围和业务规则仍须由用户确认，不得因“参考小红书”而默认要求完整复制其全部功能。

## 待确认的产品使命

在进入首个业务 Spec 前，需要由用户确认：

1. 男性用户的具体人群划分和首要切入场景；
2. 目标用户当前面临的核心问题；
3. 除“男性社区”外更具体的核心价值；
4. 第一阶段需要验证的关键假设；
5. 首期功能范围和明确不做的事项；
6. 安全、隐私、内容治理、合规和可访问性等不可妥协原则。

## 使命声明模板

> LittleBlueBook-Web 为【目标用户】提供【核心能力】，帮助他们解决【核心问题】，并通过【差异化方式】实现【可验证的结果】。

在上述信息被确认前，本模板不得被擅自填充为具体产品结论。
